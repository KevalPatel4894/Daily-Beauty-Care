# Daily Beauty Care Project Rules

- **Code Quality**: Keep code clean, modern, and localized.
- **Git Commit Workflow**: After completing each feature, verify with `./gradlew assembleDebug`, then perform `git add .`, `git commit -m "..."`, and `git push`.
- **Localization**: Always update all 8 language folders (`values-de`, `values-es`, `values-fr`, `values-hi`, `values-ja`, `values-ko`, `values-pt`, `values-ru`) whenever adding new string resources.
